# KatArbitrDownloader

Веб-инструмент для скачивания всех документов из вкладки «Электронное дело» дела на kad.arbitr.ru и их конвертации в Markdown — чтобы потом удобно отдать дело AI-агенту (PDF съедает в разы больше токенов, чем обычный текст).

**Скачать можно тут:** [github.com/zentkhv/KatArbitrDownloader/releases](https://github.com/zentkhv/KatArbitrDownloader/releases)

## Что нужно для работы

- Установленный браузер **Google Chrome** — инструмент управляет им в фоне, чтобы скачивать документы с сайта. Если его нет, скачать можно [отсюда](https://www.google.com/intl/ru/chrome); ссылка на скачивание есть и в самом интерфейсе.
- Доступ к kad.arbitr.ru. Если сайт попросит подтвердить вход или решить капчу — сделай это в открывшемся окне Chrome, инструмент сам терпеливо подождёт.

**Важно:** как только запускается «Разведка» или скачивание, открывается окно Chrome — **обязательно переключись на это окно** и дождись, пока полностью загрузится страница «Электронное дело». Если окно останется в фоне и страница не успеет загрузиться, скачивание не начнётся.

## Как пользоваться

1. Выбери папку для сохранения результатов — кнопкой «Выбрать папку...» или вписав путь вручную. Все параметры этого дела (ссылка, темп, диапазон страниц, список страниц с пропусками после последней актуализации) хранятся прямо в этой папке и подтягиваются сами при повторном выборе.
2. Вставь ссылку на карточку дела с kad.arbitr.ru (вида `https://kad.arbitr.ru/Card/...`).
3. При желании нажми «Разведать» — чтобы узнать, сколько страниц в «Электронном деле», получить возможность ограничить скачивание диапазоном страниц и сохранить в папку общую информацию о деле (`info.txt`). Откроется окно Chrome — переключись на него и дождись загрузки страницы «Электронное дело» (см. «Что нужно для работы» выше).
4. Нажми «Начать» — пойдёт скачивание. Здесь тоже откроется окно Chrome — не забудь переключиться на него и дождаться загрузки страницы «Электронное дело», иначе скачивание не начнётся. Ход виден в статусной плашке, счётчиках и журнале внизу страницы.
5. Когда дело уже собрано один раз, для последующих проверок и докачки новых документов используй «Актуализировать» — дело живое, в него со временем подшивают новые документы.

## Кнопки и переключатели интерфейса

### Блок «Дело и папка»

- **Поле «Папка для сохранения» / «Выбрать папку...»** — куда складывать результаты. Кнопка открывает системный диалог выбора папки Windows; то же самое можно вписать вручную — параметры подгрузятся, когда поле теряет фокус.
- **Поле «Ссылка на дело»** — ссылка на карточку дела на kad.arbitr.ru.
- **Конвертировать PDF в Markdown после скачивания** (флажок) — если включено, после скачивания PDF-файлы сразу конвертируются в `.md`.

### Блок «Темп и диапазон страниц»

- **Темп скачивания** (ползунок) — сколько документов в минуту скачивать. Диапазон ограничен безопасными значениями, чтобы не попасть под блокировку сайта за слишком частые запросы.
- **Разведать (страницы + инфо о деле)** — без скачивания документов узнаёт, сколько всего страниц в «Электронном деле», и сохраняет в папку тему дела, номера, дату начала, длительность и участников по категориям (`info.txt`).
- **Страницы для скачивания** (два ползунка) — ограничивает скачивание конкретным диапазоном страниц; становится доступно после «Разведки». По умолчанию — все страницы.

### Блок «Действия»

- **Начать** — полное скачивание документов (в заданном диапазоне страниц, если он указан), с опциональной конвертацией в Markdown.
- **Только PDF→MD** — конвертирует уже скачанные PDF в Markdown без обращения к сайту вообще — пригодится, если скачивание уже было, а конвертация нет, или её нужно повторить.
- **Стоп** — останавливает текущую задачу (скачивание, актуализацию, конвертацию или разведку). Продолжить позже можно той же кнопкой запуска — уже скачанное не перекачивается.
- **Начать новый сбор** — сбрасывает поля формы и удаляет `state.json` выбранной папки; сами скачанные документы не трогает.
- **Таблица по документам** — открывает в новой вкладке отчёт по всем документам дела (см. ниже).

### Блок «Актуализация»

- **Докачать то, чего не хватает** (флажок) — если включено, при актуализации недостающие документы сразу докачиваются в том же проходе; если выключено — актуализация только проверяет и показывает, чего не хватает, без скачивания.
- **Актуализировать** — обходит все страницы «Электронного дела», сверяет их с уже собранными документами (по внутреннему id документа на сайте, а не по имени файла — это надёжнее) и переносит в `vanished/` документы, которые раньше были скачаны, но больше не найдены на сайте.

### Страница отчёта («Таблица по документам»)

- **Скачать как Excel** — выгружает ту же таблицу в файл `.xlsx` с рабочими гиперссылками на PDF.
- **Поле поиска** — фильтрует таблицу по тексту (название документа).
- **Все / Собранные / Пропавшие** — фильтр строк таблицы по статусу документа.

## Какие файлы создаются в выбранной папке

```
<папка>/
  download/        — скачанные PDF-файлы
  md/               — PDF, сконвертированные в Markdown (по одному файлу на документ)
  vanished/         — документы, которые раньше были скачаны, но при актуализации больше не найдены
                      на сайте (переносятся сюда вместе со своим .md; из общего реестра не удаляются,
                      только помечаются как пропавшие)
  manifest.json     — реестр всех документов дела: внутренний id документа на сайте, название, имя
                      файла, ссылка на PDF, даты скачивания/конвертации/последней сверки с сайтом
  run_log.txt       — журнал выполнения с таймстампами (копится, не перезатирается)
  info.txt          — сведения о деле (тема, номера, дата начала, длительность, участники по
                      категориям); создаётся и обновляется при каждой «Разведке»
  state.json        — последние введённые в интерфейсе параметры для этого дела (ссылка, темп,
                      диапазон страниц, список страниц с пропусками) — чтобы при повторном выборе
                      этой же папки форма заполнилась сама
```
